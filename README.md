# Профиль Кости Дербышева

Статический сайт для GitHub Pages (ветка `main`, корень репозитория). Сборки нет: `index.html`, `career.html`, `mama.html`, `styles.css` и `app.js` рисуют страницы из `data.json` и `news.json`.

Заголовки и цифры — Oswald, текст — Onest. Оба шрифта с кириллицей, цифры с `tabular-nums`. График очков рисуется по ширине карточки: от 360 px помещаются все матчи, даты через одну, если подписи не влезают. Столбцы сравнения сезонов не шире 560 px и высотой 260 px.

На сайте имя — «Костя Дербышев». Отчество, точную дату рождения и ссылку на личную карточку игрока не добавляйте. Год рождения и названия команд можно.

## Карьера

`career.html` считает карточки из уже лежащих данных. Новые цифры туда вручную не вписываются:

- игры и сумма очков — по строкам `gameLogs`;
- лучшая игра — максимальные очки в этих строках;
- место — число из текста результата в `lastMatch`, если там есть «3-е»;
- максимумы очков и перехватов — из `tournamentStats.seasons`;
- подборы и передачи 2025/26 и сравнение с прошлым сезоном — из `trend`.

Полосы сравнения — доля от лучшего среднего среди трёх турниров. Это не оценка от 0 до 99.

## Для мамы

`mama.html` берёт строки последних игр из журнала U12 по датам в `mama.games` и дописывает короткий плюс из поля `plus`. Числа в `plus` должны совпадать с журналом и с блоком «Последний матч».

Игра без личного протокола лежит в `mama.pending`. Туда можно писать счёт команды из новости клуба и прямо сказать, что очков Кости нет.

## Новости команды

`news.json` правится вручную. Сайт сам посты не скачивает.

| Поле | Что писать |
| --- | --- |
| `caption` | Одна строка над списком |
| `sources` | Ссылки на Telegram, VK и сайт клуба |
| `posts[].date` | `ГГГГ-ММ-ДД` |
| `posts[].sort` | Если дата одна, большее число стоит выше |
| `posts[].tag` | `2014` или `клуб` |
| `posts[].title`, `text` | Короткий пересказ. Счёт команды можно, личную статистику Кости из новости не выводить |
| `posts[].link` | Ссылка на пост, только `http` или `https` |

Вакансии, наборы и длинные отчёты про другие года рождения не добавляйте. Фильтр на странице: «Все», «2014», «Клуб». Блок есть на карьере и на странице для мамы.

## Что ещё можно добавить

1. Когда появится личный протокол сезона 2026/27, добавьте строку в журнал. Карточки карьеры пересчитаются сами. Имеет смысл завести отдельный турнир в `gameLogs`.
2. Фото в щиток — только свой кадр.
3. Карта бросков — только если в протоколе будут координаты.
4. Сравнение с командой — когда опубликуют средние состава.
5. Общий рейтинг, цветные плашки и уровни бейджей не добавлять: таких чисел в протоколах нет.

Локальный просмотр (нужен HTTP, не открытие файла):

```bash
python3 -m http.server 8000
```

Дальше откройте `http://127.0.0.1:8000/`.

## Структура `data.json`

Корень — объект с блоками страницы. Порядок разделов задаёт массив `nav`. `label` — заголовок на странице, `short` — короткая подпись в полосе меню: Матч, Профиль, Сезон, Турниры, Игры, Динамика, Оценка, Источники. На телефоне эта полоса липкая и появляется после карточки игрока. Шапка с именем прячется при скролле вниз и возвращается при скролле вверх.

| Ключ | Что на странице |
| --- | --- |
| `player` | Шапка: `name`, `team`, `position`, `summary` |
| `nav` | Меню разделов: `id`, `label`, `short` |
| `lastMatch` | Блок «Последний матч» |
| `profile` | Карточки профиля и абзац |
| `season` | Матчи сезона 2026/27 без протокола и таблица группы А |
| `tournamentStats` | Средние и броски по турнирам |
| `gameLogs` | Переключатель поматчевых журналов |
| `trend` | Столбчатое сравнение сезонов |
| `notes` | «Что уже получается», «Над чем работать», короткий вывод |
| `mama` | Тексты страницы «Для мамы»: вступление, плюсы к играм, игра без протокола |
| `sources` | Ссылки на турниры |

Десятичные в JSON пишутся с точкой (`4.3`). На сайте средние показываются с одним знаком и запятой (`4,3`): так же, как `toFixed(1)`. Целые в журналах остаются целыми (`11`, не `11,0`). Строки бросков (`"14/57, 25%"`) копируются как есть, сайт их не пересчитывает.

Поле `"highlight": true` выделяет строку команды или сезона. В таблице группы оно стоит у «Росток-2014», в средних — у сезона 2025/26.

### Средние, `tournamentStats.seasons`

Оба блока (средние и броски) читают один и тот же массив. Колонки: `averageColumns` и `shootingColumns`. У средней колонки `"average": true`.

Поля сезона: `name`, `games`, `minutes`, `points`, `rebounds`, `assists`, `steals`, `turnovers`, `fg2`, `fg3`, `ft`.

### Журналы, `gameLogs.tournaments`

У турнира есть `id`, `label`, `columns` (`key` + `label`) и `rows`. Открытый по умолчанию турнир — `gameLogs.defaultId` (`u12`).

График очков рисуется только если у турнира есть `chart`:

- `labelKey` — поле подписи (у U12 это `date`);
- `labelPrefix` — сколько первых символов взять (`5` превращает `28.09.25` в `28.09`);
- `valueKey` — поле высоты столбца (`points`).

У «Быстрого прорыва» и «Движения вверх» графика в исходных данных нет, только таблицы.

### Динамика, `trend.views`

Два переключателя: `avg` («Игра») и `ctrl` («Контроль мяча»). У вида есть `categories` и `series`: имя серии и массив `values` той же длины, что и категории. Значения — средние за игру, на графике подписываются с запятой. Какой вид открыт сначала, решает `trend.defaultId`.

Фолы и «фолы на нём» есть только в виде `ctrl`, в таблицах средних их нет. Меняйте эти числа прямо в `values`, сайт их не выводит из журнала.

## Добавить игру в журнал

1. Откройте нужный турнир в `gameLogs.tournaments`.
2. Добавьте объект в конец `rows`. Ключи те же, что у соседних строк.

Пример для «Росток U12»:

```json
{
  "date": "ДД.ММ.ГГ",
  "opponent": "Соперник",
  "score": "00:00, победа",
  "minutes": "00:00",
  "points": 0,
  "fg2": "0/0",
  "rebounds": 0,
  "assists": 0,
  "steals": 0,
  "turnovers": 0
}
```

Если у турнира задан `chart`, новый столбец появится сам. После серии игр пересчитайте средние вручную и поправьте объект в `tournamentStats.seasons` (очки, подборы, передачи, перехваты, потери, броски). Сайт средние не суммирует.

Новый турнир — ещё один объект в `tournaments` со своим `id`, `label`, `columns` и `rows`. Чтобы открывать его кнопкой, этого достаточно. График очков включите объектом `chart`, если в строках есть числовое поле очков.

## Обновить таблицу группы

Правьте `season.standings.rows`. Колонки: `team` (с местом, как `6. Росток-2014`), `played`, `wins`, `losses`, `points`, `scored`, `conceded`. Все значения — строки, чтобы не появилась лишняя десятая.

У строки «Росток-2014» оставьте `"highlight": true`, у остальных это поле не нужно. Подпись даты в `season.caption` тоже обновите, например: «По состоянию на 2 ноября 2026».

## Заменить блок «Последний матч»

Полностью замените объект `lastMatch`.

- `caption` — что считается последним протоколом и какая игра ещё без протокола.
- `facts` — три карточки: матч, дата и стадия, результат. Можно добавить или убрать карточку: рисуются все элементы массива.
- `columns` и `rows` — протокол. `rows` — массив строк, обычно одна. Число ячеек в строке равно числу колонок.
- `paragraphs` — текст разбора, каждый элемент с нового абзаца.

Текущие колонки: «Старт», «Мин», «Очки», «2-очк.», «Штраф», «Подб (нап)», «Пер», «Перехв», «Потери», «Фолы».

Игру без протокола в текущем сезоне держите в `season.matches` (поля `title`, `detail`, `status`). Когда протокол появится, перенесите цифры в `lastMatch`, а в `matches` смените `status` или добавьте следующую игру в начало массива.
